# Skills self-assessment

Everyone scores themselves from 1 to 5 on eight skills, once in their first week and again in the final week. The change gives you a visible record of what you learned, and it gives the project evidence of what the internship taught ([project plan](../plan/neonradar-project-plan.md), "Learning track"; "Definition of done": "Skills self-assessment completed at both ends, deltas recorded").

You fill in the table in your own learning log ([_template.md](_template.md) has it). Nobody else scores you, and no agent fills it in for you ([OD-5](../build/operator-decisions.md)).

## The eight skills

The skills come from the project plan; the second column says what each one means in this project.

| Skill | In NeonRadar |
|---|---|
| Graph modelling | Choosing nodes, relationships and properties; reading and questioning the graph schema (contract C2) |
| Cypher | Writing and reading queries: patterns, traversals, aggregation, parameters, query plans |
| Entity resolution | Deciding when two records describe the same person or company, and measuring how often that decision is right (Phase 2) |
| AML domain knowledge | Typologies, indicators and the project's terminology, read from the primary sources the project cites (`docs/sources/bibliography.yaml`, from milestone M1.10a) |
| Vue | The explorer UI: Vue 3 components with `<script setup>`, Pinia, Vue Router, Cytoscape.js |
| Docker | Running the local stack: Compose, volumes, memory limits, logs |
| Code review | Reading someone else's pull request, asking "why this and not that", checking the tests and the evidence |
| Working effectively with AI | Specifying work so that it can be checked, checking AI output against sources, tests and fixtures, and knowing when not to use it |

## The scale

Pick the highest line that is true today. The scale is a suggestion for comparable scores; the project lead may adjust it before the first scores are written, and then it stays fixed until the end.

| Score | Meaning |
|---|---|
| 1 | I have not used it, or I only know the name |
| 2 | I can follow along when someone shows me |
| 3 | I can do routine tasks on my own, with documentation |
| 4 | I can handle non-routine tasks and explain my choices to others |
| 5 | I could teach it, and review other people's work in it with confidence |

## When

- **Start:** in your first week, before the work changes your view of yourself. Write it in the same pull request as your first log entry.
- **End:** in the final week, next to your exit post. Do not change your start scores, even if they now look wrong; note that in your log instead, because it is part of what you learned.
- At the end the community manager collects the start and end scores from the logs for the final report.
