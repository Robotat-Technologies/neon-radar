# Security policy

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue, discussion or pull request about them.

- Use GitHub private vulnerability reporting: the **Report a vulnerability** button on the repository's **Security** tab.
- Or email **TODO: security contact not set yet (`project.security_contact` in `docs/build/project.yaml`)**.

Tell us what you found, how to reproduce it and what an attacker could do with it. If the issue involves personal data from a public source, describe it without copying the data into the report.

We will acknowledge your report within 7 days and keep you informed until it is resolved. NeonRadar is a volunteer open-source project and has no bug bounty.

## Supported versions

NeonRadar has not been released yet. Until the first release, only the `main` branch is supported, and fixes land there.

| Version | Supported |
|---|---|
| `main` | Yes |
| Anything else | No |
