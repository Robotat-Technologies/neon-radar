# NeonRadar documentation

An index of the `docs/` tree. Folders marked "later" are created by a later Phase 1 milestone; see [build/PHASE-1.md](build/PHASE-1.md) section 4.2 for the full repository layout.

| Folder | What it holds | Status |
|---|---|---|
| [build/](build/) | The build spec ([PHASE-1.md](build/PHASE-1.md)), project facts ([project.yaml](build/project.yaml)), [operator decisions](build/operator-decisions.md), the [progress log](build/PROGRESS.md), the [CI and repository protection guide](build/ci.md) and, later, phase reports in `reports/` | present |
| [research/2026-10-16/](research/2026-10-16/) | Verified research notes behind the build spec: stack, Neo4j, data sources, synthetic data and AML domain sources | present |
| [plan/](plan/) | The project plan (an export) | present |
| [decisions/](decisions/README.md) | Architecture decision records (ADRs), their index and template | present |
| [sources/](sources/README.md) | The [bibliography](sources/bibliography.yaml): citation keys for every factual AML statement, and how to cite | present |
| [glossary.md](glossary.md) | The terms the documentation and the interface use, with their sources | present |
| [wording.md](wording.md) | The disclaimers, the vocabulary for text about entities, the forbidden patterns and the documentation rules | present |
| [typologies/](typologies/README.md) | Plain-language typology explainers and the catalog index | present |
| [learning/](learning/README.md) | Learning logs (written by people, never by agents), the log [template](learning/_template.md), the [skills self-assessment](learning/skills-self-assessment.md), the [teach-back](learning/teach-back.md) rota, the [reading list](learning/reading-list.md) and the [case notes](learning/cases/README.md) | present |
| [team/](team/) | [Assignment 1](team/assignment-1.md), [first queries](team/first-queries.md), [Assignment 2](team/assignment-2.md) and [squads and roles](team/roles.md) | present |
| [data/](data/) | Data source [spike reports](data/spikes/); licence notes come later | present |
| [architecture/](architecture/) | The [architecture overview](architecture/overview.md) and the [local Neo4j stack](architecture/local-stack.md) | present |

Repository-level documents live in the root: [README](../README.md), [CONTRIBUTING](../CONTRIBUTING.md), [DATA_SOURCES](../DATA_SOURCES.md), [SECURITY](../SECURITY.md), [CODE_OF_CONDUCT](../CODE_OF_CONDUCT.md), [CHANGELOG](../CHANGELOG.md) and [CONTRIBUTORS](../CONTRIBUTORS.md). What may be committed under `data/` is in [data/README.md](../data/README.md).
