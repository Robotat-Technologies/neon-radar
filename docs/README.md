# NeonRadar documentation

An index of the `docs/` tree. Folders marked "later" are created by a later Phase 1 milestone; see [build/PHASE-1.md](build/PHASE-1.md) section 4.2 for the full repository layout.

| Folder | What it holds | Status |
|---|---|---|
| [build/](build/) | The build spec ([PHASE-1.md](build/PHASE-1.md)), project facts ([project.yaml](build/project.yaml)), [operator decisions](build/operator-decisions.md), the [progress log](build/PROGRESS.md) and, later, phase reports in `reports/` | present |
| [research/2026-10-16/](research/2026-10-16/) | Verified research notes behind the build spec: stack, Neo4j, data sources, synthetic data and AML domain sources | present |
| [plan/](plan/) | The project plan (an export) | present |
| [decisions/](decisions/README.md) | Architecture decision records (ADRs), their index and template | present |
| `sources/bibliography.yaml` | Citation keys for every factual AML statement | later |
| `typologies/` | Plain-language typology explainers | later |
| `learning/` | Learning logs (written by people, never by agents), templates, reading list and case notes | later |
| `team/` | Assignments, roles and `first-queries.md` | later |
| `data/` | Data source spike reports and licence notes | later |
| `architecture/` | Architecture overview | later |

Repository-level documents live in the root: [README](../README.md), [CONTRIBUTING](../CONTRIBUTING.md), [DATA_SOURCES](../DATA_SOURCES.md), [SECURITY](../SECURITY.md), [CODE_OF_CONDUCT](../CODE_OF_CONDUCT.md), [CHANGELOG](../CHANGELOG.md) and [CONTRIBUTORS](../CONTRIBUTORS.md). What may be committed under `data/` is in [data/README.md](../data/README.md).
